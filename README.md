# Room App

## About

Room App is a simple Android to-do list application. Users can add and delete tasks, which are stored locally on the device.

## Features

- Sign in with the demo credentials: `dsw@gmail.com` / `password`
- Add and delete tasks
- View when each task was created
- Keep tasks saved locally between app launches

The registration and password recovery screens are currently placeholders and are not functional.

## Built with

Kotlin, Jetpack Compose, and Room.
